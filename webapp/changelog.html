Changelog

What's changed in Nestpane, release by release. No marketing spin — just what shipped and why.

2.1.1

October 22, 2026

Version bump only — the Chrome Web Store would not accept 2.1.0 a second time. No functional changes beyond what's listed under 2.1.0 below; this is the build that actually ships.

2.1.0

October 21–22, 2026
  • Fixed a data-loss bug: notes and journal entries could be lost if your browser closed or discarded the tab before you clicked Save — most noticeable on Brave. Both now autosave as you type, and save immediately the moment the tab goes to the background, not just when you remember to click Save.
  • Fixed Google sign-in dropping on every new tab in Brave: your sign-in session is now kept across new tabs instead of being thrown away every time one opens.
  • Fixed a Google Drive sync bug: under specific timing, a device's own newer changes could get stuck and never make it to your Drive backup. Local changes now always sync up unless another device's backup is genuinely newer — exactly the behavior you'd expect from any syncing app.
  • Added safe storage upgrades: a versioned migration system with an automatic backup before any future upgrade touches your data, and an automatic rollback if anything goes wrong.
  • Added a web dashboard (see below) and started laying the groundwork for Firefox support.
