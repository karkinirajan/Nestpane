Privacy Policy for Nestpane

Last updated: August 31, 2026  ·  See also: Terms of Service

Nestpane ("the extension", "we", "our") is a Chrome extension that replaces the new tab page with a local-first productivity dashboard. This policy explains exactly what data Nestpane accesses, where it is stored, and what — if anything — leaves your device. Nestpane has no servers of its own: there is no analytics, no telemetry, no advertising, and no account system operated by the developer. Every network request it makes is listed by name in the sections below.

1. Summary

  • All of your data (bookmarks, notes, tasks, journal, habits, settings, etc.) is stored locally on your device using Chrome's storage.local API.
  • Optional Google Drive sync stores an encrypted or plain backup of that same data in a hidden, app-private folder in your Google Drive — we cannot access it.
  • Optional AI features send your prompt (and only your prompt) directly from your browser to Anthropic, using an API key you provide and store on your own device.
  • We do not sell, rent, or share your data with any third party. We do not run ads or trackers.
  • Uninstalling the extension, or clearing its storage, deletes all locally stored data.

2. Data Stored Locally (on your device only)

Nestpane stores the following in Chrome's storage.local, which is sandboxed to this extension and never transmitted anywhere by Nestpane itself unless described in §4–§5 below:

  • Bookmarks, notes, and tasks you create or import
  • Journal entries, mood logs, and habit-tracker history
  • Kanban boards, reading queue, and saved tab sessions
  • Calendar events, focus-mode settings, and blocked-site lists
  • Theme, accent color, and other display preferences
  • Your Google OAuth access/refresh tokens, if you sign in (see §4)
  • Your Anthropic API key, if you enable AI features (see §5) — stored under a separate, non-synced key and excluded from Drive backups

4. Google Account Sign-In and Drive Sync (optional)

If you choose to sign in with Google, Nestpane obtains an access token for the following scopes. In Google Chrome, this uses chrome.identity.getAuthToken() — Chrome's built-in Google sign-in for extensions, which caches and refreshes the token itself; Nestpane never stores it. In other Chromium-based browsers (Brave, Vivaldi, Opera, Arc, Edge), where that Chrome-only mechanism isn't available, Nestpane falls back to the standard chrome.identity.launchWebAuthFlow() extensions API instead — the token is kept in memory only for that browser session and is never written to disk. Neither path involves a client secret.

  • userinfo.email and userinfo.profile — to show your name/email in the sidebar
  • drive.appdata — to read and write a single backup file in your Drive's hidden, app-specific data folder

The drive.appdata scope is intentionally restrictive: it grants access only to a hidden folder that belongs to Nestpane — it cannot see, list, or modify any other file in your Google Drive. The access token is never sent anywhere except Google's own token endpoints (oauth2.googleapis.com) and the Drive API (www.googleapis.com).

Optional end-to-end encryption: if you set a passphrase, your Drive backup is encrypted on-device with AES-GCM (key derived via PBKDF2, at least 12 characters required) before upload. Your passphrase is stored locally on your device in chrome.storage.local and is never transmitted anywhere — if you lose it (or clear your browser data), the backup cannot be recovered, including by us.

Nestpane's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Your Google data is used solely to provide the sync feature you explicitly enabled, is never used for advertising, and is never transferred to any third party.

5. Optional AI Features (Anthropic)

Nestpane includes an AI command bar, an AI daily briefing, and AI-assisted "Smart Organize". These features are off by default and require you to enter your own Anthropic API key in Settings.

When enabled, the following is sent directly from your browser to https://api.anthropic.com/v1/messages, using your API key:

  • Ask AI / command bar: the text you typed
  • Daily briefing: a short summary of the titles of your pending tasks for today
  • Smart Organize: the titles and URLs of your currently open tabs, plus the names of your existing bookmark folders

This data is sent only to Anthropic, governed by Anthropic's Privacy Policy. Nestpane's developer never receives, stores, or has access to this data or your API key — the key is stored only in your local chrome.storage.local, is excluded from Drive sync and end-to-end encrypted backups, and is sent only in the x-api-key header of requests you initiate.

6. Optional Voice Capture (Web Speech API)

If you use Voice Capture, your microphone audio is processed by your browser's built-in speech-recognition service (governed by your browser vendor's own privacy policy, e.g. Chrome's), not by Nestpane or its developer. Nestpane only receives the resulting transcribed text, which is stored locally like any note, task, or journal entry.

8. Data Retention and Deletion

All local data lives in Chrome's storage.local for this extension and is deleted automatically when you uninstall Nestpane, or immediately if you use the "Clear All Data" option in Settings → Data Management. If you enabled Drive sync, you can delete your backup at any time by revoking Nestpane's access at myaccount.google.com/permissions, which removes Nestpane's hidden app-data folder along with it.

9. Security

  • All user-generated content is HTML-escaped before being displayed — no eval, no innerHTML with unsanitized input.
  • All user-supplied URLs are validated to be http(s) only.
  • OAuth tokens are stored only in chrome.storage.local, never in chrome.storage.sync.
  • All network requests Nestpane makes are over HTTPS.

10. Children's Privacy

Nestpane is not directed at children under 13 and does not knowingly collect data from children.
